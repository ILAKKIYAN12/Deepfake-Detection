# 🔍 Deepfake Detection using Machine Learning

![Python](https://img.shields.io/badge/Python-3.13-blue)
![PyTorch](https://img.shields.io/badge/PyTorch-2.0-red)
![OpenCV](https://img.shields.io/badge/OpenCV-4.x-green)
![License](https://img.shields.io/badge/License-Academic-yellow)

A deep learning project that detects whether a video is **REAL or DEEPFAKE**
using ResNet50 and OpenCV face detection — no dlib required!

---

## 🎯 What This Project Does

- Analyzes videos frame by frame
- Detects faces using OpenCV
- Classifies each face as REAL or FAKE
- Gives a final verdict with percentage score
